How to install

  1. Tap Download for Android and wait for the APK file to finish downloading. Open the downloaded file to begin installation.
  2. If Android says your browser is not allowed to install apps, tap Settings, turn on Allow from this source for your browser, then go back and continue the installation. This is a normal, one-time permission for apps installed outside Google Play.
  3. When Android asks, tap Install.
  4. Open ProductivityPet Demo from your apps.

Only one message means stop: if Play Protect says this app is harmful, do not override that warning and do not install it. The permission prompt in step 2 is normal and safe to continue.

This is a demo APK installed outside Google Play, so Android asks for extra permission to install it. It is a separate app and only uses data stored on your own phone.
